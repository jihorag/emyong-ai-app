# 3-2-1 곱셈
## 📌 단원 개관

『수학 2-2』 곱셈구구에서는 **동수누가**의 원리로, 『수학 3-1』 곱셈에서는 묶음의 개념으로 (두 자리 수)×(한 자리 수)를 익혔다. 이 단원에서는 ==(세 자리 수)×(한 자리 수), (한 자리 수)×(두 자리 수), (두 자리 수)×(두 자리 수)==로 수의 범위를 확장한다.

지도 시에는 답을 바로 제시하지 않고, **수 모형·모눈종이** 등 구체물을 이용해 학생 스스로 곱셈의 알고리즘이 형성되는 과정을 탐구하도록 돕는다. 각 차시에서 발견한 원리가 이전 차시와 어떤 점에서 같고 다른지 비교하며 차시 간 학습이 연결되게 한다. 단원 주제인 '지속 가능한 삶'과 연계해 재생 종이·대나무 칫솔·코코넛 수세미 등 친환경 소재로 실생활 곱셈 문제를 구성한다.

## 🧩 부분 곱의 합과 넓이 모델

- **부분 곱의 합** — 곱해지는 수를 자릿값별로 나누어(예: 268=200+60+8) 각각 곱한 뒤 더하는 원리가 세로 형식(표준 알고리즘)의 바탕이다. 수 모형으로는 **백의 자리부터** 계산되지만, 세로 형식에서는 **일의 자리부터** 계산하며 올림을 표기하는 방식으로 간략화한다.
- **넓이 모델(모눈)** — (한 자리 수)×(두 자리 수), (두 자리 수)×(두 자리 수)에서 새로 등장한다. 곱하는 수를 두 부분(예: 25×13 → 25×10과 25×3)으로 나누는 **2분할 모델**을 사용해 세로 형식 계산과 자연스럽게 연결한다. *(4분할 모델은 학생에게 더 어려워 이 단원에서는 다루지 않는다.)*
- **곱하는 수가 10배가 되면 계산 결과도 10배**가 된다는 성질(예: 20×3=60 → 20×30=600)을 이용해 (몇십)×(몇십), (몇십몇)×(몇십)을 계산할 수 있다.

## ⚠️ 주요 오개념·오류 유형

- **곱셈구구 오류** — 두 수의 곱 자체를 잘못 계산 (예: 7×40의 부분 곱을 240으로 오답)
- **부분 곱의 자릿값 오류** — 57×48에서 57×40의 부분 곱을 57×4로 잘못 계산하거나, 자릿값에 맞지 않는 위치에 적음
- ==올림 처리 오류== — 올림을 아예 하지 않거나(예: 57×30을 1710이 아닌 1510으로), 올림한 수를 곱하기 전에 먼저 더해 버리는 오류(예: 57×2에서 7×2=14의 올림 1을 50에 먼저 더해 60×2로 계산)
- **부분 곱의 끝자리 0 오류** — 42×50을 42×5로 계산하거나, 생략되는 0의 개수를 잘못 인식

==어림셈으로 계산 전후 결과를 검증하는 습관==을 들이면 이런 오류를 스스로 발견하고 교정할 수 있다.

## 🧭 차시별 지도 방안 (핵심 원리)

**(세 자리 수)×(한 자리 수) — 올림 없음·한 번·여러 번 (2~4차시)** — 수 모형으로 백·십·일 모형을 각각 곱해 **부분 곱의 합**을 구한 뒤, 세로 형식으로 형식화한다. 올림이 한 번(3차시)에서 여러 번(4차시)으로 늘어나며, 올림한 수를 십의 자리·백의 자리 위에 표기해 다음 자리 곱에 더하는 절차를 익힌다.

**(몇십)×(몇십), (몇십몇)×(몇십) (5차시)** — 곱하는 수가 10배가 되면 결과도 10배가 됨을 이용해(20×3=60 → 20×30=600), 나아가 (몇십몇)×(몇십)은 십의 자리·일의 자리로 나눈 부분 곱의 합(14×20 = 10×20 + 4×20)으로 계산한다.

**(한 자리 수)×(두 자리 수) (6차시)** — 모눈종이(넓이 모델)에서 곱하는 두 자리 수를 십의 자리와 일의 자리로 나누어(예: 7×14 = 7×10 + 7×4) 부분 곱의 합으로 구한다. 3학년 1학기에 배운 (두 자리 수)×(한 자리 수)와 비교하며, 곱셈에서 두 수의 순서를 바꾸어도 계산 결과가 같음을 간접적으로 경험한다.

**(두 자리 수)×(두 자리 수) — 올림 한 번·여러 번 (7~8차시)** — 모눈종이의 2분할 모델로 곱하는 수를 십의 자리와 일의 자리로 나누어(예: 25×13 = 25×10 + 25×3) 부분 곱의 합을 구하고 세로 형식으로 형식화한다. 계산 전 **어림셈**(예: 25×13 → 30×10=300)으로 결과의 타당성을 미리 점검한 뒤, 실생활 문제를 만들고 해결한다.

**정리 (9~11차시)** — 곱셈 빙고 놀이, '환경을 지키는 녹색 소비'와 연계한 실생활 문제 해결, 단원 확인 학습으로 마무리한다.

## 📝 지도상의 유의점

- 알고리즘을 기계적으로 암기시키기보다, 학생이 **부분 곱의 합 원리를 스스로 발견**하도록 수 모형·모눈종이 등 구체물 활동을 충분히 제공한다.
- 세로 형식 계산은 일의 자리부터 계산하지만, 부분 곱은 논리적으로 어느 자리부터 구해도 무방함을 비교해 학생이 그 이유를 이해하게 한다.
- 올림한 수는 덧셈의 받아올림과 달리 **곱셈 후에 더해야 함**을 분명히 지도한다.
- 곱셈 계산 전후로 **어림셈**을 활용해 결과의 타당성을 확인하는 습관을 기른다.
- 계산 기능 숙달이 목적이 아닌 문제에서는 계산기 사용을 허용한다.
- 문제 해결 과정을 설명할 때 다른 친구의 의견을 존중하고 경청하는 태도를 함께 기른다.
