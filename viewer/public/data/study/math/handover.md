# 수학과 (초등 임용고시)

## 과목 개요

초등 임용고시 수학 과목은 **수학 교육론**과 **교과 내용학** 두 축으로 구성됩니다.

### 수학 교육론 (1차 시험 핵심)
수학 교육의 이론적 배경과 교수법을 다룹니다.
- **학습 이론**: 피아제의 인지 발달, 오수벨의 유의미 학습, 게슈탈트 통찰 학습
- **수학 학습 모형**: 개념 형성 모형, 속성 모형, 원리 탐구 모형, 문제 해결 모형
- **표상 이론**: EIS 표상 단계(Enactive-Iconic-Symbolic)
- **반 힐레 기하 사고 수준**: 5단계(시각화→분석→비형식적 추론→형식적 추론→공리적)
- **실제주의 수학 교육(RME)**: 수평적·수직적 수학화, 유도된 재발명
- **오수벨의 선행 조직자**: 포섭이론, 점진적 분화, 통합적 조정
- **브루너**: 나선형 교육과정, 발견 학습, 직관적·분석적 사고

### 교과 내용학 (각론)
학년별 수학 내용과 교수법을 다룹니다.
- **수와 연산**: 자연수, 분수, 소수, 사칙연산
- **도형**: 평면도형, 입체도형, 대칭, 합동
- **측정**: 길이, 무게, 들이, 각도, 넓이
- **규칙성**: 패턴, 함수, 비례
- **자료와 가능성**: 그래프, 확률

### 출제 경향
- 특정 학자의 이론 적용 사례 분석 (빈출: 오수벨, 반 힐레, 디네스)
- 교과서 지도 방법 및 오개념 분석
- 학년별 수학 개념 도입 방법

## 학습 전략
1. 핵심 이론 → 핵심어 암기 → 적용 사례 연습
2. 이론 상호 비교 (예: 발견 학습 vs 수용 학습)
3. 기출문제로 출제 패턴 파악
